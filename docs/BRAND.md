# ContextOS identity

**ContextOS** is the display name. **Keep the thread.** is the tagline.
The repository, distribution, Python import, and command retain their existing names:
`personal-brain-mcp`, `personal_brain_mcp`, and `personal-brain-mcp` respectively.

The mark is an open pair of brackets containing lines of context. Original vector artwork
uses system sans-serif and monospace fonts with no external font or image dependencies.

| Color | Value | Use |
|---|---|---|
| Indigo | `#4859F5` | Mark and primary accent |
| Ink | `#16234C` | Light-theme type |
| Mist | `#EFF2FD` | Light canvas |
| Midnight | `#111A35` | Dark canvas |
| Lime | `#B7ED87` | Retrieval signal |
